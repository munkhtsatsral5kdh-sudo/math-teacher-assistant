# Физикийн виртуал лаборатори (public/fizlab.html): шинэ лаборатори нэмэх заавар

## Ерөнхий
- **Нэг HTML файл**, гаднаас юу ч татдаггүй тул интернэтгүй ажиллана. Багш энэ файлыг 26 таблет руу хуулж Chrome-оор нээдэг. Тиймээс CDN, фонт, гадны зураг **бүү ашигла**.
- QR үүсгэгч (qrcode-generator, MIT) ба QR уншигч (jsQR, Apache-2.0) файл дотроо шахагдсан байгаа.
- Сайт дээр `/fizlab` хаягаар нээгдэнэ (next.config.js-ийн rewrite). `vercel.app` дээр нээгдэх үед "← Багшийн туслах" товч гарна.
- Хэл: монгол. Хүүхдэд ойлгомжтой, монгол ахуйтай холбосон байна (гэр, худаг, тооно, Наадам, Гүррагчаа гэх мэт).
- Шинжлэх ухааны хувьд үнэн зөв байна: тоо, нэгж, томьёог шалга. Хялбарчилсан бол (үрэлтгүй гэх мэт) дэлгэц дээр бич.

## Бүтэц
- `UNITS`: 16 нэгж (Ф6.1–Ф9.4). `LABS`: лаборатори бүр `{id, grade, unit, date, title, codes, ready, build:()=>Class}`. Шинэ лаборатори нэмэхдээ `ready:true` болгоод `build`-ийг холбоно.
- Лаборатори бүр PhET шиг 2 горимтой:
  - **"▶ Багштай хийх"**: виртуал багш **Ухаана** алхам алхмаар чиглүүлнэ. Нэр шаардана, оноо, түвшин (I–IV) тогтооно, төгсгөлд QR гаргана.
  - **"🧪 Чөлөөт туршилт"**: нэргүй, багшгүй, `Class.free`-ийн сорилт даалгаврууд гарна.

## Лабораторийн класс (жишээ: Lab6Gravity, Lab7Temp, Lab8Pulley)
```
class LabX {
  constructor(bus, free)   // canvas #cv, удирдлага #ctrl, хүснэгт #dataTable
  size()                   // devicePixelRatio, W, H, байрлалууд (this.L)
  destroy()                // listener-үүдийг салгах, #ctrl, #dataTable цэвэрлэх
  setMode(m)               // 'lab' эсвэл тусгай горим; удирдлагыг идэвхгүй болгох
}
LabX.steps  = N            // явцын мөрний алхмын тоо (bot.task/bot.step)
LabX.qs     = [...]        // асуултуудын богино нэр, асуух дарааллаар (багшийн тайланд)
LabX.free   = [...]        // чөлөөт горимын сорилт даалгаврууд (**тод** зөвшөөрнө)
LabX.script = async (bot, lab, bus) => { ... }
```
- Үйлдэл бүрийг `bus.emit({type:'...', ...})` гэж мэдээлнэ. Скрипт нь `await bus.wait(pred)` гэж хүлээнэ. `bus.mark()` ба `wait(pred, true)` нь зөвхөн шинэ үйлдлийг хүлээнэ.
- Виртуал багш:
  - `bot.say(text, cls)`
  - `bot.ask(q, opts, correctIdx, good, hint, explain)`: эхний оролдлогоор зөв бол 2 оноо, 2 дахь оролдлогоор 1 оноо.
  - `bot.predict(q, opts, correctIdx)`: зөв бол 1 оноо.
  - `bot.button(label)`
  - `bot.task()`: даалгавар биелсэнд 1 оноо.
  - `bot.step()`
- Дүрслэл: canvas дээр вектороор зурна. Туслах функцүүд: `roundRect`, `arrow`, `lin`, `mulberry`, `cloud`, `mountains`, `ger`, `glow`, `forceArrow`. Чирэх, товших хоёуланг дэмжинэ (pointer events).

## Шалгах
- Хэвтээ (1280×800) ба босоо таблет (800×1280) хэмжээнд Playwright-аар "Багштай хийх" урсгалыг эхнээс нь дуустал ажиллуулж, `pageerror` гараагүйг шалга. Дэлгэцийн зургийг харж давхцал байгаа эсэхийг шалга.
- QR: үр дүнгийн QR-ыг багшийн хэсгийн "🖼 Зургаас уншуулах"-аар уншуулж шалга.

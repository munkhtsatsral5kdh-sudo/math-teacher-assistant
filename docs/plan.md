# Сайтын төлөвлөгөө

## Зорилго
- **Сурагч (6–9-р анги):** хаанаас ч, хэзээ ч орж хичээлээ нөхөх, чөлөөт цагаа үр бүтээлтэй өнгөрөөх. Дунд ангийн хүүхдэд нэг хараад ойлгогдохоор маш энгийн байх.
- **Багш:** зөвхөн нэг багш ашиглана. Бие даалтын даалгавар өгөх, хичээл дээр (ухаалаг самбар, 26 таблет) ашиглах.
- **Агуулга:** шинжлэх ухааны хувьд 100% үнэн зөв онол, томьёо, жишээ, зөвлөгөө. Монгол ахуйтай холбох.
- Сумын интернэт тогтворгүй тул хөнгөн байх, боломжтой бол интернэтгүй ажиллах.

## Мэдэгдэж буй асуудал (заавал засах)
1. **Багшийн хэсэг нууцлагдаагүй:** хэн ч /teacher/... хаягаар орж өөрчилж чадна.
2. **Бүх өгөгдөл Supabase-ийн нэг мөрөнд хадгалагддаг** (`app_state`, id="main", store.js + cloud.js). Олон сурагч зэрэг хадгалахад бие биенийхээ дүнг дарж бичнэ. RLS дүрэм нь anon хэрэглэгчид бүгдийг бичих эрх өгдөг.
   - Шийдэл: багш Supabase Auth-аар нэвтэрдэг болох. Сурагчийн ажил (attempts, submissions) тусдаа хүснэгтэд мөр мөрөөр хадгалагдах. Багшийн өгөгдлийг зөвхөн нэвтэрсэн багш бичдэг болгох.
   - Supabase SQL-ийг багш өөрөө Supabase-ийн SQL Editor-т хуулж ажиллуулна. Алхам бүрийг энгийнээр заа.
